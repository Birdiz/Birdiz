# Birdiz

Birdiz is a multi-service Dungeons & Dragons toolkit stack:

- `api`: Node.js + Express + MongoDB driver
- `web`: Next.js frontend
- `mongo`: MongoDB

## Quick Start

```bash
docker compose up --build
```

- Web: `http://localhost:3000`
- API: `http://localhost:4000`
- MongoDB: `localhost:27017`
